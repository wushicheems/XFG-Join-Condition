## XFG 计算机工程 组织 · 加入条件

---

### 一、基础准入条件（硬性门槛，全部满足）

| 条件 | 具体说明 |
|------|----------|
| **年级范围** | 六年级 ~ 大学二年级 |
| **编程基础** | 熟练掌握**至少一种**编程语言（Python / JavaScript / Java / C++ 等） |
| **硬件设备** | 拥有在家可正常使用的电脑（能运行代码编辑器+浏览器） |
| **GitHub账号** | 拥有个人GitHub账号，且能基本使用 `git clone / add / commit / push` |
| **时间承诺** | 长假期（寒暑假/小长假）能参与开发 |
| **学习意愿** | 愿意主动学习新技术、阅读文档、参与代码审查 |
| **态度底线** | 不抄袭他人代码用于提交、不泄露团队内部项目 |

---

### 二、AI 使用立场（XFG 核心主张）

> **XFG 鼓励所有成员在日常开发中积极使用 AI 工具（如 ChatGPT、DeepSeek、Gemini、GitHub Copilot 等）。**

我们相信：
- **AI 是生产力工具**，不是作弊——会用 AI 写出更好的代码，是现代工程师的基本素养
- **提问能力 = 工程能力**：能把问题描述清楚、能判断 AI 给出的答案是否靠谱，比死记语法更重要

### 五、退出与留队机制

| 状态 | 条件 |
|------|------|
| **留队** | 每月有代码提交 或 参与项目讨论 |
| **荣誉成员（保留队籍）** | 连续2个月无提交，自动转入，随时可激活 |
| **正式退出** | 主动申请退出，或连续1年无任何活动 |
